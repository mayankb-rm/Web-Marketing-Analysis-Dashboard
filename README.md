## 📌 Problem Statement

With millions of digital interactions occurring across web platforms, it's crucial for marketing and analytics teams to measure **user behavior**, **device traffic**, **engagement patterns**, and **conversion gaps**.

The **Web Marketing Dashboard** provides a full-funnel view of performance metrics across:
- 💡 Session behavior  
- 📱 Device breakdowns  
- 📄 Pageviews & exits  
- 🌍 Country-level engagement  

This report empowers digital marketers to make **data-informed UX decisions**, improve **bounce rates**, and enhance **marketing ROI**.

---

## 🛠️ Steps Followed

**Step 1**: Imported web analytics dataset into Power BI Desktop.

**Step 2**: Used Power Query to clean and reshape:
- Standardized session and bounce fields
- Parsed timestamps and page titles

**Step 3**: Created DAX measures:
- Total Sessions, Unique Pageviews, Exit Rate, Bounce Rate
- Average Time on Page, Avg Page Load Time

**Step 4**: Designed visuals to capture:
- Monthly trends, device category distribution
- Top-performing pages, bounce/session correlation
- Geographic engagement map

**Step 5**: Published to Power BI Service for web-based access

## 🔍 Key Insights

- 📉 Bounce rate is **highest on mobile**, indicating a possible need for mobile optimization or UI improvements.  
- 📈 Sessions consistently grew from January to August, peaking at **30K+ in August**.  
- 🖱️ **Exit pages align with long load times**, highlighting an urgent UX improvement opportunity.  
- 🌍 High engagement in **Western markets** offers room for regional targeting and campaign localization.
